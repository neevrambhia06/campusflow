# CampusFlow 🎓

> **College Assignment & Experiment Workflow Tracker**

CampusFlow is a student-focused academic workflow management application designed around the real-world college submission cycle:

**Moodle Assignment → Perform Experiment → Create Upload Template → Upload to Moodle → Faculty Checking → Completed**

---

## ✨ Features

- **Academic Workflow Tracking**: Track each experiment's lifecycle with independent checklist steps and dynamic progress tracking.
- **Subject & Semester Organization**: Organize subjects across Semesters 1 through 8 with custom codes, colors, and assigned faculty.
- **Action Required & Deadlines**: Priority dashboard highlighting assignments that need immediate attention and upcoming deadlines.
- **Submissions Hub**: Filter and review completed experiments ready for mid-term and final lab submissions.
- **Calendar View**: High-level timeline of release and submission due dates.
- **Clean Academic Light Theme**: Built with a focused, minimal, and high-readability light interface.
- **Local Persistence**: Client-side storage via Zustand `localStorage` persistence.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **State Management**: Zustand
- **Routing**: React Router v7
- **Icons**: Lucide React
- **Date Utilities**: Date-fns

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/neevrambhia06/campusflow.git
cd campusflow
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
